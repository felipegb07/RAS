# Proyecto Hovercraft
Este repositorio tiene la finalidad de mostrar los diferentes elementos que componenen el proyecto *hovercraft*, de tal manera que podamos hacer una correcta inclusión y representación de los elementos al momento de mostrar todo.

---

## Materiales
Los materiales que se usarán son:
1. Microcontrolador ESP32.
2. Sensor ultrasonido hc-sr04.
3. Diseño de overcraft en SolidWorks.
4. 2 baterías WZS 18650 8800mAh.
5. 2 motores de corriente coreless de 3.7V.
6. Servomotor sg90.
7. 2 Controladores de velocidad.

### Diagrama de componenetes.
Aquí se hace la implementación de los componentes haciendo uso del software tinkercad.

### Código nodos ROS y Platformio
Aquí se hace la implementación de la ruta hacia los códigos que se cargarán en la ESP32, de tal manera que se puede hacer el proceso de los controladores.
